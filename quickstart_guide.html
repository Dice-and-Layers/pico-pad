SS MACRO KEYBOARD
Quick Start
Getting Started
1
Connect to PC or Mac
Connect the keyboard using a USB-C cable. It will mount as an external USB drive named CIRCUITPY. No drivers or software installation required!
2
Open Web Configurator
Open Google Chrome, MS Edge, or Opera and navigate to: sathishrazor.github.io/mackro-keyz/ or scan the QR code.
3
Customize & Save Instantly
Click Connect, choose the CIRCUITPY drive, click any key in the 3x3 grid to assign custom hotkeys, macros, or media keys, and click Save Config!
Factory Defaults
KEY 1-3 Edit Copy/Paste/Save
KEY 4-6 Media Mute/Vol-/Vol+
KEY 7-9 Macros Dev/Email/Lock
Need help or support?
Contact us via the Amazon Messaging system for official prebuilt kit warranties,
or visit our open-source project page: github.com/sathishrazor/mackro-keyz
